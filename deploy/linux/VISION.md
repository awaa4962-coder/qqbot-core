# 图片与对话

Linux `1.4.22-vision-context` 使用已选中的当前输入、引用和近期原话理解图片，不在每次聊天前额外调用语境分析模型。

`1.4.39-stable-cache` 已上线，为客观描述加入同范围在途共用：精确图片摘要/布局、用户、群或私聊、模型与路由/思考快照、提示词和隐私修订全部相同才合并。最多8项计算、每项16个等待者、40秒；各等待者按自己的异步作用域复核来源与取消，一个退出不误杀其他有效等待者。全部退出、遗忘或截止后拒绝晚到结果，底层未结束不提前释放容量。完成后的共享请求控制也不允许续用。

它只复用客观画面，不包含当前聊天推断、最终答案或发送。模型能直接接收图片时仍走原像素路径，不为了使用本地缓存额外调用描述模型；因此不承诺每次对话省费。管理界面分别显示客观描述缓存读取和共享等候；未知的旧版共享数据不伪报为0，API前缀缓存统计仍单独按供应商报告计量。

`1.4.43-image-input` 的 evidence-v5 是待验收解读候选，不是新的识别提供方。`QQBOT_IMAGE_CONTEXT_ROLLOUT` 为空时保留稳定v3，群号列表仅切指定群，`all` 留到灰度验收后扩展。该部署设置不放宽白名单，群灰度不改变私聊。规则在本轮入口捕获，原图、描述降级和备用聊天沿用同一份；提示词版本区分v3/v5，动态风格不改变规则。

v5仅组织已选资料：当前提问和图片进入同一条消息，问题原文不改；历史与引用仍按原有上下文组整体保留，工具结果不转为普通文字。来源中的消息发送人不是图片创作者或人物身份，安全消息编号用于对应原话。无图片与灰度外仍走稳定路径。v4的32次主备真实对照存在6个候选反例，未通过语义验收；v5须另行验收，不以离线测试替代，也不重复上一批付费请求。

新版把字面画面、提供的原话和情境关系分开表达。反差可支持反话解读，不能单凭反话证明心理动机；来源明确说了意图时可带来源复述。具体原文、受控模型结果、前端与单群观察分别验收，不能只用提示词断言勾选语义通过。客观描述缓存仍只由原客观任务控制，不存新版最终语境答案。

## 实际路径

1. 当前附件、已核验引用图片、明确指向的近期图片沿用原选择规则。近期图片要求匹配作者/引用且在五分钟内，不读取已遗忘、撤回、删除或被纠正来源；图片原消息作为有来源的上下文层，不能随意换成旁人的图。
2. 安全下载一次，在内存中解码、旋转并规范化为 JPEG。聊天主备共用这份本轮资源，不把图片 URL 交给模型访问。
3. 实际聊天插槽声明 `vision` 时，规范化图片与已选文字直接进入同一请求；不先丢掉细节变成短摘要。不支持 `vision` 时才调用既有视觉任务主/备生成客观描述，再交给文字聊天插槽。
4. 每个插槽使用自己的模型配置与干净请求。备用继续保留，不复用主模型的私有推理/原生续接，也不把主模型的猜测当作视觉事实。

能力标记来自真实配置，不靠模型名猜测；标记为支持不保证第三方接口真能收图。请求失败走现有备用，不偷偷替换供应商。思考档位配置不变：自动档仍按原规则识别图片输入，显式档位优先。

## 边界与限制

- 每轮最多选三张唯一图片，不用后面的图替补失败项；来源下标仍对应原输入位置。
- 单图下载最多 10 MiB，输入最多 4000 万像素，最长边最多 2048；JPEG 单图最多 1.5 MiB、累计 4.5 MiB。不放大原图，超限/坏图单独失败。
- GIF 等动态图片仅处理第一帧并明确标注，不宣称理解完整动画；超小文字和压缩后细节可能丢失。SVG/PDF 不进入图片解码器。
- 只有本轮后端生成并注册的 JPEG 数据可以从 24000 字符文本/协议预算中单独计量，仍有图片字节/数量限制。签名、私有续接、工具参数和文字不会被豁免；同一图在多次模型回合中仍会重新发送并计费。
- 客观识别最多两个配置的视觉插槽，各一次 HTTP 尝试、20 秒超时、512 完成 token 请求上限、256 KiB 接收上限，两槽共用40秒总截止。它不是聊天工具四回合的一部分；各活动模型任务的独立预算见模块目标实现，实际费用仍以供应商用量为准。
- 失败时明确提示图片未读取，不伪造看到的人物、文字或动作。语境判断可能出错，提示词要求区别可见画面与猜测，不保证所有梗都理解。

## 缓存与隐私

旧全局相似指纹描述缓存不再参与聊天看图，也不再在停机时重写；原文件保持不动，表情模块的相似图片指纹仍保留用途。

新缓存只存客观描述，按用户、群/私聊、原图片字节 SHA-256、图片排列/规范化尺寸、实际视觉提供方配置与提示词版本隔离。最多 128 条/128 KiB，单条最多 800 字符，绝对期限十分钟，命中不续期；不缓存语境答案或失败，不跨范围合并，重启清空。遗忘和偏好/记忆修订会同步清空缓存，在途处理重新检查代次和权限。

图片仅在内存中规范化，原图和 base64 不进入诊断或新持久化文件。文字脱敏并不能清除像素中的隐私；不要上传含密钥、身份证等资料的截图。请求过的图片已交给供应商，本地遗忘不能撤回供应商收到的数据。既有 QQ/群历史附件记录及私有备份沿用原留存规则，不宣称本次改动清除了所有旧副本。

## 诊断

控制台“诊断”显示“原图与对话一起理解”“客观描述兜底”“复用同范围客观描述”或“图片未能读取”，以及可读、失败、超限和首帧数量。只显示元数据，不显示图片正文、下载 URL、描述内容或推理。
