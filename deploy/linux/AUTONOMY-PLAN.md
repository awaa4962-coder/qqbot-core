# Linux 工具自主调度实施计划

日期：2026-10-09。用户批准参考 DeepSeek Harness，将工具调度交给模型；只限制实际权限，不依靠固定句式决定模型能否使用工具。本批目标版本为 2.1.0，原 2.0.0 的 55 项已完成记录和延期质量失败不改写。

## 实现原则

- 模型可直接回答，也可自行调用当前有权限的工具，再根据真实结果继续推理和回答。工具错误返回结构化结果，不代替模型输出固定回复。
- 内置工具与 MCP 工具共享注册表、会话身份、执行预算、取消、隐私失效和结果边界；不引入另一套 Agent、记忆、日报或发送系统。
- 取消公开搜索的固定句式和必须逐字复制当前问题的限制；仍尊重禁止联网，拒绝凭据、会话标识和明确私有内容外发。普通插话只开放本地只读能力，不默认增加后台联网。
- 草稿准备不依赖固定命令词。本人保存/提醒仍需本人确认，模型不能确认；其他用户、群或收件人不能由模型参数越权指定。
- MCP 初期只接人工配置允许的只读工具，默认无服务、无工具。远端只读标记不视为安全证明，连接、工具开关、状态和结果在现有前端可见；不开放裸 OneBot 管理或任意系统执行。
- 按普通聊天/轻量插话选择有界预算，允许管理员配置；主备与嵌套模型调用共享同一预算，不能靠切换模型重置。
- Linux 独立开发和部署；Windows 冻结。普通插话10%、表情50%、模型/思考/凭据/名单、JM与大写FS、关系公式和reserved导出保持。MCP或工具权限开关不替代既有群/好友访问许可。

## 并行范围

主任务持有注册表接口、会话/循环、预算、调用方接线、前端与发布。公开搜索、草稿准备和MCP适配分配互不交叉的写入范围；统一接口后集成。至少两轮非作者审查已授权范围和安全边界；子代理不得提交、部署、调用真实模型或发送QQ。
